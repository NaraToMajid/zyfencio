Mengelola Projek
Bagaimana cara membuat projek baru?
Klik tombol Projek Baru di dashboard atau halaman Projek Saya. Isi nama projek (wajib), deskripsi opsional, dan pilih visibilitas. Klik Buat Projek.
Apa perbedaan projek Publik dan Privat?
Publik: Semua orang bisa melihat projek dan file-nya di halaman Jelajahi.
Privat: Hanya kamu yang bisa mengakses projek ini. Tidak muncul di pencarian publik.
Bagaimana cara mengunci file agar tidak dilihat publik?
Di dalam halaman projek, klik tombol pada file yang ingin dikunci. File terkunci tidak akan bisa dibuka oleh pengunjung, meskipun projek bersifat publik.
Apakah ada batas jumlah file per projek?
Saat ini tidak ada batasan jumlah file per projek. Namun harap gunakan dengan bijak agar performa tetap optimal untuk semua pengguna.
Bagaimana cara menghapus projek?
Masuk ke halaman projek, klik menu Pengaturan Projek, lalu pilih Hapus Projek. Perhatian: tindakan ini permanen dan semua file akan ikut terhapus.
Menggunakan Zyvedit

Zyvedit adalah editor kode berbasis browser yang terintegrasi langsung dengan projek-mu di Zyvenqo.

Bahasa pemrograman apa yang didukung?
Zyvedit mendukung syntax highlighting untuk: HTML, CSS, JavaScript, TypeScript, Python, PHP, XML, JSON, Markdown, dan file teks umum lainnya.
Bagaimana cara menyimpan file?
Tekan Ctrl + S (atau Cmd + S di Mac) untuk menyimpan. Kamu juga bisa klik tombol Simpan di toolbar. Status simpan ditampilkan di pojok kanan atas.
Apa itu fitur Preview?
Jika kamu sedang mengedit file .html, klik tombol Preview untuk melihat tampilannya langsung di browser tanpa harus deploy ke server. Berguna untuk mengecek tampilan website secara cepat.
Bagaimana cara upload gambar ke projek?
Klik tombol Upload di panel file (ikon ). Gambar akan diupload ke storage Zyvenqo dan URL publiknya tersimpan sebagai konten file, sehingga bisa langsung digunakan di kode HTML-mu.
Pesan & Chat
Bagaimana cara mengirim pesan ke pengguna lain?
Buka halaman Pesan, gunakan kotak pencarian untuk menemukan username yang dituju, lalu klik nama mereka untuk memulai percakapan.
Apa itu Chat Global?
Chat Global adalah ruang obrolan publik yang bisa diakses semua pengguna Zyvenqo. Semua pesan yang dikirim di sini dapat dibaca oleh semua pengguna yang aktif. Cocok untuk diskusi umum, tanya jawab, atau sekedar ngobrol dengan komunitas.
Bisakah saya mengirim gambar di pesan?
Ya! Klik ikon di area input pesan untuk memilih gambar dari perangkatmu. Gambar akan diupload dan ditampilkan langsung di percakapan.
FAQ Umum
Kenapa akun saya belum bisa masuk setelah registrasi?
Akun baru memerlukan verifikasi oleh admin. Biasanya proses ini berlangsung dalam beberapa jam. Pastikan kamu mendaftar dengan data yang valid. Jika sudah lebih dari 24 jam, coba hubungi admin.
Bagaimana jika saya lupa password?
Saat ini fitur reset password dilakukan melalui admin. Hubungi admin dengan menyertakan username kamu untuk mendapatkan bantuan reset password.
Bisakah saya menghapus akun saya?
Penghapusan akun dilakukan melalui admin. Hubungi admin dengan permintaan penghapusan akun. Semua data, projek, dan file kamu akan ikut terhapus secara permanen.
Apakah Zyvenqo gratis?
Ya, Zyvenqo sepenuhnya gratis untuk digunakan. Tidak ada biaya tersembunyi. Semua fitur yang tersedia dapat digunakan tanpa perlu berlangganan.
Apakah Zyvenqo bisa diakses dari HP?
Ya, Zyvenqo responsif dan dapat diakses dari perangkat mobile. Namun untuk pengalaman mengedit kode terbaik, disarankan menggunakan komputer atau laptop.
